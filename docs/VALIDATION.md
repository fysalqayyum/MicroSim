# Validation status and acceptance rules

This document separates software qualification from scientific validation.
The distinction is important: a scheduler-complete, finite calculation is not
automatically a calibrated material simulation.

## Current maintained baseline

The `KKS_OpenCl` `Function_F=4` repair was exercised with a controlled binary,
two-phase directional-solidification case using one MPI rank and one OpenCL
GPU. The private research case, scheduler configuration, machine identity, and
run directories are not part of this repository.

## Passed software gates

- Local and HPC source files matched by SHA-256.
- Long floating-point input tokens parsed without the former fixed-buffer
  overflow.
- Temperature-dependent F4 lookup reproduced its host spline reference to
  small interpolation error.
- The repaired anisotropic and anti-trapping paths stayed finite in controlled
  isolation tests.
- Binary output wrote the composition field rather than the chemical-potential
  field.
- Restart input restored the stored blocks into their matching arrays.
- Restart initialization repaired ghost and displacement state.
- Restart physics gates used absolute time.
- A forced moving-window shift preserved finite fields and performed liquid,
  composition, and temperature refill.
- Default OpenCL optimization matched all stored reference fields in the
  reduced qualification case and materially reduced its measured wall time.
- A promoted one-GPU executable completed its smoke test with a zero exit code
  and finite fields.

## Rejected or incomplete paths

- Two- and four-rank OpenCL runs did not preserve one-rank field equivalence
  near periodic/internal x boundaries. They are not accepted for production.
- A formal thresholded-area spatial convergence gate failed, although a
  continuous phase-integral diagnostic was much closer. The original gate is
  not retroactively changed.
- Extended seeded cases showed interface motion but did not yet establish a
  robust dendritic morphology.
- Interfacial kinetics, molar volume, anisotropy, noise, mesh/interface
  convergence, and the two-dimensional approximation still need sensitivity
  analysis or experimental calibration.

## Restart acceptance

Use a continuous reference and a segmented run generated by the same source
and executable.

1. Run continuously from step 0 to step `N`.
2. Run to checkpoint `R`.
3. Restart from `R` and continue to `N`.
4. Compare every stored field at `N`.
5. Report absolute and relative norms, extrema, and non-finite counts.

A relative L2 difference near `1e-6` is a clean continuation target. A
tolerance around `1e-4` can be a practical GPU acceptance ceiling when exact
operation ordering is not guaranteed. The tolerance must be declared before
the comparison and applied to every required field.

## Required field diagnostics

At minimum, report:

- non-finite count for each phase, chemical potential, composition, and
  temperature field;
- phase and composition minima/maxima;
- phase-sum error;
- temperature range;
- global composition drift;
- interface position from a sub-cell `phi=0.5` crossing;
- cumulative moving-window shift;
- solid area and interface roughness when morphology is claimed.

## Meaning of status terms

| Status | Meaning |
|---|---|
| Builds | Source compiles and links in the recorded environment |
| Scheduler-complete | Job reached a terminal success state |
| Finite | Required stored fields contain no NaN or Inf |
| Coupling-qualified | Thermodynamic/temperature paths respond as intended |
| Restart-qualified | Segmented and continuous fields meet declared tolerances |
| Window-qualified | Trigger/shift/refill plumbing passes |
| Morphology-qualified | Quantitative interface evolution meets predefined gates |
| Calibrated | Simulation observables agree with independent experimental data |

Do not collapse these levels into a single “validated” label.
